# Decisiones del taller S3 · Día B

## Decisión 1 — la tabla en pantalla estrecha

Elegimos la mecánica 1: la tabla se desplaza dentro de su propio espacio porque la florista necesita conservar las cinco columnas, especialmente la hora de entrega y el estado, cuando trabaja desde el celular.
Para el rol florista, la consecuencia es que puede consultar el pedido completo sin que la página entera se desplace de lado.
Lo que se pierde es la lectura simultánea de toda la fila en el ancho del celular: debe desplazar horizontalmente el recuadro para revisar las columnas que no están visibles.

## Decisión 2 — columnas del listado

Elegimos número de pedido, entrega, ramo, entrega a / zona y estado porque son los datos que la florista necesita para priorizar, preparar y entregar cada ramo.
La consecuencia es que puede ordenar mentalmente el trabajo por hora y saber qué acción sigue sin abrir cada pedido.
Lo que se pierde es mostrar en esta vista el precio, la forma de pago y el detalle completo de componentes; esos datos quedan para la ficha del pedido.
